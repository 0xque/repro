01 / Workflow

Make “can’t reproduce” testable.

REPRO keeps the sequence and the check together. A confirmation screen can look right while the app writes the wrong data.

  1. 01 / Capture

    Record the failure.

    Capture the approved fixture’s browser steps in a dedicated Chromium session.

  2. 02 / Review

    Decide what leaves.

    Review the retained data before exporting. Inspect the file without running it.

  3. 03 / Verify

    Run the same check.

    Replay against the old and fixed versions. Compare the stored outcome, not just the screen.

02 / Boundaries

What works today.

This is a focused prototype, not a recorder for arbitrary websites.

Tested

One synthetic checkout fixture on Linux with Chromium and PostgreSQL. The demo restored a known starting state and compared database rows using the same recorded actions.

Not shipped

No public installer, arbitrary app recording, or capsule uploads. The product repository remains private. This page only shows synthetic example results.
